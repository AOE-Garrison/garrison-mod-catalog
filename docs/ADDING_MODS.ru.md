# Как добавить мод, картинку и описание

## Где что хранится

Каждый мод — отдельная папка `mods/<id>/`. В ней два файла:

- `mod.toml` — обычный текстовый файл UTF-8 с подписанными полями;
- `cover.jpg` (или PNG/WebP) — обложка 1600×600, не больше 4 МиБ.

Префикс у картинки не нужен. Имя должно точно совпадать с полем `cover`.
ZIP мода загружается в Releases: не кладите SGA, ZIP, сцены Blender или исходники игры в Git.

## Новый мод

Из корня этого репозитория:

```powershell
gh auth login
python scripts/new_mod.py my-mod --name "Название мода" --author "overbait"
```

Заполните созданный `mods/my-mod/mod.toml`:

| Поле | Что писать |
| --- | --- |
| `release_tag` | Уникальный тег, например `my-mod-v0.1.0` |
| `asset` | Имя ZIP в релизе: `my-mod-0.1.0.zip` |
| `cover` | `cover.jpg`, либо пустая строка при отсутствии обложки |
| `details.id` | Постоянный ID, совпадающий с папкой |
| `name` | Название карточки |
| `version` | Версия из трёх чисел, например `0.1.0` |
| `summary` | Краткое описание, максимум 180 символов |
| `author` | Имя автора |
| `updated` | Дата публикации `YYYY-MM-DD` |
| `min_garrison` | Минимальная версия Garrison |
| `description` | Подробности и инструкция запуска для кнопки `i` |
| `changelog` | Изменения текущей версии |

Имена карты и tuning внутри игры впишите в инструкцию запуска. Тип MAP/TUNING берётся из `mod.bundle.json` автоматически.

Добавьте картинку, затем закоммитьте и отправьте папку мода:

```powershell
git add mods/my-mod
git commit -m "Add My Mod metadata and cover"
git push origin main
python scripts/publish_mod.py my-mod D:/Mods/my-mod.zip
```

Скрипт проверит исходный ZIP и контрольные суммы SGA, добавит описание и обложку, создаст новый GitHub Release. Исходный ZIP останется нетронутым. Дождитесь зелёного **Build mod catalog** в Actions, затем нажмите **Sync** в Garrison.

Если после push проверка сообщает об отсутствующем релизе, сначала выполните `publish_mod.py`: публикация запустит проверку повторно. При другой ошибке смотрите лог Actions. Последний корректный каталог не заменяется ошибочным.

## Обновление

Измените версию, тег, имя ZIP, дату и changelog; сохраните прежний ID и ключи bundle/member. Повторите commit, push и publish. Не перезаливайте старый релиз: новая версия нужна даже для исправления уже выпущенного ZIP.

## Доступ и подключение

Репозиторий закрытый. Bjorn и overbait имеют admin как владельцы AOE-Garrison.
На другом компьютере нужен GitHub CLI с входом `gh auth login` в аккаунт с доступом к этому репозиторию. Токены не вписываются в TOML/JSON и не пересылаются вместе с модами.

В Garrison → Mods → Catalog → Source:

```text
https://api.github.com/repos/AOE-Garrison/garrison-mod-catalog/contents/catalog.json?ref=main
```

Нажмите Sync. Каталог меняется только после явной синхронизации; установка/обновление мода — отдельное действие. Сам каталог не выбирает карту или tuning в игровом лобби.
